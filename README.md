# サムネイル

1280×670 px のフレームに画像を配置し、中央の 670×670 px ガイドを見ながら、単色またはグラデーションを塗って PNG で書き出すツールです。文字入れはありません。

## 開発

```bash
npm ci
npm run dev
```

表示された URL をブラウザで開きます。

## 操作

- 画像をドロップするか、「画像を選ぶ」から読み込みます。
- ドラッグで位置、ホイールまたは「拡大」で大きさを変えます。矢印キーでも 1px ずつ動かせます（Shift で 10px）。
- 「フレームに合わせる」はフレーム全体を覆う大きさです。「ガイドに合わせる」は中央の正方形を覆う大きさです。
- 「ガイドでマスク」をオンにすると、正方形の外側は塗りだけになります。
- 塗りは単色か、2色のグラデーションです。角度は度数で、0° が上、時計回りです。
- 「画像の上に重ねる」をオンにすると、同じ塗りがフレーム全体に不透明度つきで乗ります。
- 「PNGを保存」はガイド線を含めず、1280×670 px の PNG を保存します。
