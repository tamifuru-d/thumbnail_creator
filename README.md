# サムネイル

1280×670 px のフレームに画像を配置し、中央の 670×670 px ガイドを見ながら、単色またはグラデーションを塗って PNG で書き出すツールです。文字入れはありません。

## 開発

```bash
npm ci
npm run dev
```

表示された URL をブラウザで開きます。

## 操作

- 画像をドロップするか、「画像を選ぶ」から読み込みます。
- ドラッグで位置、ホイールまたは「拡大」で大きさを変えます。矢印キーでも 1px ずつ動かせます（Shift で 10px）。
- 「フレームに合わせる」はフレーム全体を覆う大きさです。「ガイドに合わせる」は中央の正方形を覆う大きさです。
- 「ガイドでマスク」をオンにすると、正方形の外側は塗りだけになります。
- グラデーションは左右から中央へ抜けて、画像を挟みます。90° で左が色1、右が色2です。0° では下と上から挟みます。角度は時計回りです。
- 初期値は角度 135°、せり出し 450px、透過率 100% です。透過率 100% では端の色は出ません。
- 「画像の不透明度」は写真の残り方です。初期値 80% で、背景色が少し混ざります。
- 「背景色」は写真の下地です。「オリーブ」で #66722F になります。塗りのオリーブは、左右の色も同じオリーブにします。
- 「ファイル名」で保存名を決めます。「PNGを保存」はガイド線を含めず、1280×670 px の PNG をその名前で保存します。
